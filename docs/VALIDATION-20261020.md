## 真实电脑 USB 拔插

所有者确认安全弹出电脑上的录像盘，再拔线等待后接回同一端口。有限观察器只读 USB/LUN/UDC 状态，短暂持现有协调锁，完成后释放；不写 USB、不调用业务启停、不改操作记录。

观察到 CONFIGURED → 安全弹出后 LUN 空 → DISCONNECTED → CONNECTED → CONFIGURED。仅 LUN 变空没有被误计为拔线。

释放观察协调锁约 **5.05 秒后**看到原录像映像重新导出；8081 仍可连接，五个后台服务的原进程组保持存活、身份已核验和就绪，active_op 内容未变，测试锁已释放并独立重新获取确认。这个间隔不是从插线开始计时，也没有通过该观察直接归因具体 watchdog 动作。

本场景仅为同一次开机、电脑 USB；没有执行实车拔插、掉电、手机重启或本轮视频播放验收。
