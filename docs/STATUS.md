# 当前整理状态

日期：2026-10-20（UTC+8）。

## 已有依据

- 当前开发环境曾完成实车录像采集，以及 iPhone Safari 远程播放。
- 网页和 HTTP 服务基线为 4.2，包含 4.1 的分段预览与切换恢复逻辑。
- 既有部署检查包括鉴权、事件索引、预览和 Range 读取。
- 用户曾在播放期间通过 Tailscale 设备 Ping 页面看到 Direct connection。这只能证明那次测试的状态。
- 仓库测试使用合成数据，不包含用户的实车录像或设备日志。
- 整理后的仓库副本通过 109 项 Python 检查、27 项播放界面检查和 22 项连接界面检查；这不替代 USB 或实车验收。

## 发布副本与设备版的区别

文件重新组织为 `web/`、`pipeline/`、`tests/`，测试相应调整相对路径。发布副本在主程序启动时额外要求非空 `TOKEN`，防止未配置访问码就启动服务；这项改动未部署回当前手机。测试中的网络地址已改为示例值。
